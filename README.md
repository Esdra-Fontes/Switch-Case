🌐 Switch Case:
---
O **Switch Case** é uma estrutura de controle utilizada para executar diferentes blocos de código com base no valor de uma variável ou expressão. Ele é uma alternativa mais organizada ao uso de múltiplos `if` e `else if`, tornando o código mais legível e fácil de manter.

📌 Objetivo do Projeto: 
---
O objetivo deste projeto é demonstrar a estrutura básica de um site e a organização de arquivos em um projeto web, servindo como base para estudos, exercícios práticos e evolução no desenvolvimento de aplicações web.

🛠️ Tecnologias Utilizadas:
---
- HTML5 – Estrutura das páginas
- JavaScript – Interatividade e comportamento dinâmico
- *(O projeto não utiliza CSS externo além do básico, focando na lógica principal.)*
